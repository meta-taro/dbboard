# Performance baseline

Generated by `cargo run --release -p dbboard-bench -- --write`. Do not
edit by hand: the next run overwrites it. `--release` is not optional —
a debug build measures the debug build, and nobody ships one.

`docs/roadmap.md` reserves the v0.14 slot for startup, connect-and-browse
and large result sets, with the condition that *measurement lands before any
optimisation, so the numbers are comparable afterwards*. This file is that
measurement. Nothing here has been optimised yet — these are the numbers as
they were found.

**These numbers describe one machine.** Comparing a run here against a run
on different hardware says nothing. Comparing two runs on the same machine,
across a change, is what the file is for.

No test asserts any number in this file. A threshold on a timing is a flaky
test, and this project has already paid for one rare intermittent failure
(ADR-0125). What *is* asserted, by `tests/baseline_drift.rs`, is that the
measurement points listed here are exactly the ones the harness measures —
so a point cannot quietly disappear and take its regression with it
(ADR-0141).
