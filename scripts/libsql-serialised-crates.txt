# Crates whose tests must run one at a time (--test-threads=1).
#
# On Windows, tearing down two in-memory libSQL databases at the same instant
# crashes the whole test binary with STATUS_ACCESS_VIOLATION (0xc0000005),
# after every assertion has already passed. The mitigation is to stop two
# teardowns from overlapping, which means running the affected test binaries
# single-threaded. It makes the crash rare rather than impossible -- one got
# through on 2026-08-22 -- so the runner retries that one signature once
# (ADR-0125). Being on this list is still what makes it rare enough to retry.
#
# The hazard is not a crate name, it is "opens libSQL in a test". Any crate
# that can reach dbboard-turso in the dependency graph -- directly or through
# dbboard-connect, as a normal or a dev dependency -- inherits it. For a long
# time only dbboard-turso was listed, and the other four failed a push on a
# green branch instead.
#
# The list is checked, not remembered:
# crates/dbboard-turso/tests/serialised_teardown.rs derives the same set from
# the workspace manifests and fails when this file disagrees. Add a crate here
# when that test tells you to; do not add one speculatively.
#
# Read by .cargo-husky/hooks/pre-commit and .cargo-husky/hooks/pre-push.
